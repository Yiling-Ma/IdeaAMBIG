# README Artwork

## Tables

All eight README tables are typeset with LaTeX, Latin Modern, and `booktabs`.
Brick-red rules and headers, warm cream section bands, and pale olive highlights
follow the project palette. The exported SVGs use outlined glyphs and a white
background to remain readable in GitHub's light and dark themes.

Each table retains its original, copyable text in the README's expandable
"View table as text" section. Directory links are available there as well.
`tables/tables.json` contains the table data, and `tables/*.tex` contains the
generated LaTeX sources. To rebuild the SVGs with a TeX distribution and Poppler:

```bash
python3 docs/render_tables.py
```

## Visual Identity

`identity/ideaambig-logo.svg` is an original vector mark: a letter A with a
deliberate gap, a detached blue completion piece, and an olive crossbar.
The design represents an implementation-critical gap and the clarification
needed to complete a specification. `identity/ideaambig-wordmark.svg` provides
the colored project name in GitHub's README heading.

The palette uses brick red (`#AB240E`), vermilion (`#ED4513`), orange
(`#F8832B`), olive (`#B5C17D`), and powder blue (`#BCDAEB`). Both assets
have transparent backgrounds for GitHub's light and dark themes.

`identity/badges/` stores the three resource badges as self-contained SVGs
generated by Shields.io. The README loads these repository files directly,
without requiring requests to an external badge service.

## Paper Figures

These images are rendered from the paper's figure PDFs in
[Yiling-Ma/-ARR-Aug--AmbIdea](https://github.com/Yiling-Ma/-ARR-Aug--AmbIdea),
at commit `30519dda90aa33acbc46e82d36382be0834c2129`.

| Image | Paper source |
| --- | --- |
| `figures/overview.png` | `figures/case_study.pdf` |
| `figures/pipeline.png` | `figures/ideabench_pipline.pdf` |

Rendered with Poppler's `pdftoppm`, preserving the paper artwork:

```bash
pdftoppm -f 1 -singlefile -scale-to 2000 -png case_study.pdf overview
pdftoppm -f 1 -singlefile -scale-to 2400 -png ideabench_pipline.pdf pipeline
```
